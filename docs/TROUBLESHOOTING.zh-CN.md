# 故障排查

[English](TROUBLESHOOTING.md) | 简体中文

按症状检查。修改本地数据前备份 `storage/`；普通启动不需要全量 OCR。

| 症状 | 检查与处理 |
| --- | --- |
| 找不到 `node` / `python3` | 安装 Node.js 22.12+、Python 3.10+，重开终端，用 `node --version` / `python3 --version` 检查。 |
| 缺 `.venv` 或 Python 导入失败 | 在根目录运行 `./scripts/install.sh`，依赖安装到项目内。Windows 用 README 手动命令。 |
| `npm ci` 失败 | 检查 Node 版本和依赖仓库网络；保留锁文件，不要为掩盖依赖问题删除它。 |
| 本地地址打不开 | 保持 `npm start` 运行，用 `http://127.0.0.1:4173` 而非直接打开 HTML，查看终端错误。 |
| 4173 端口被占用 | 使用已有实例或正常停止；也可 `npm start -- --port 4174`，打开新端口。权限/语言按站点保存。 |
| 仍显示旧界面 | `npm run build`，重启后端，再刷新。`npm start` 只在缺构建时自动构建，不会每次检查源码改动。 |
| Vite 可开但 API 失败 | 后端运行于 4173，开发代理指向此端口；Vite 页面通常在 5173。 |
| 题库为空 | 点击体验演示题或运行 `npm run demo`，也可导入资源包；公开检出不含私有题库。 |
| 导入提示 ID 已存在 | 相同内容可重复；不同内容用 CLI `--replace`，或为真正不同的包使用新 ID。 |
| 导入拒绝未知字段 | 使用可移植输入格式，不是生成后的 exam JSON；对照[导入说明](IMPORTING.zh-CN.md)检查字段/类型。 |
| 网页无法导入含媒体 JSON | 使用 `npm run import:pack -- "/path/to/pack.json"` 导入文件夹；网页只支持纯文字。 |
| 媒体路径被拒绝 | 文件应在包目录内，路径使用 `/`；避免 `..`、隐藏路径、符号链接、不支持扩展名，并检查大小。 |
| 无法解码音频/读取时长 | 确认播放器能打开且格式受支持，安装项目依赖；改后缀不是音频转换。 |
| 私有 PDF 导入缺文件/清单 | 该导入只支持原已知目录和配套私有 `verified_*.json`，公开仓库不含；新内容用资源包。 |
| OCR 不可用 | 单独安装 Tesseract 和英文 `eng`，用 `tesseract --list-langs` 检查；演示/JSON 不需 OCR。 |
| 严格模式不可用 | 查看资料校验；自定义包与 Essentials 不限时，源冲突/缺音/未核切分会关闭私有严格范围。 |
| 旧会话提示来源变化 | 旧内容/历史冻结；必要时恢复匹配资产以复盘/重练，或新建当前版本练习，不改旧答案迁就新键。 |
| 没声音 | 检查站点静音、系统输出、准备音量及自动播放权限，使用页面重试/恢复，严格故障会记录。 |
| 麦克风拒绝 | 在浏览器给当前本地地址权限，并在系统隐私中允许浏览器；选正确输入并测试回放。 |
| 录音待上传/不完整 | 保持页面和服务运行以重试，不清浏览器数据；缺片段/结束标记与听感质量是两件事。 |
| 录音可播但不能拖动 | 完整录音可能需重建本地容器索引；项目 FFmpeg 使用流复制，失败仍保留原分段。 |
| 刷新/休眠后时间继续 | 正常，服务器拥有时钟；刷新不重置，迟到答案不会保存到下一题。 |
| 复盘/资料库被锁 | 完成或主动结束活动严格会话；限制同时作用于其他标签/会话。 |
| 分数和 ETS 量表不同 | 软件只给可靠客观原始结果与独立自评，不生成官方标定分。 |
| 切中文后题文仍英文 | 原题语言有意保留；切换翻译应用控件/帮助，不翻译考试内容。 |

## 安全诊断

项目根目录运行：

```sh
node --version
python3 --version
npm run typecheck
```

服务运行时打开[健康检查](http://127.0.0.1:4173/api/health)。正常响应标识本地服务/存储；不要把整个题库、答卷、录音贴到公开 issue。反馈提供版本、系统/浏览器、简短错误和尽量用演示复现的步骤。见[贡献](../CONTRIBUTING.zh-CN.md)与[安全政策](../SECURITY.zh-CN.md)。

## 备份恢复

待上传录音完成后，Control+C 停服务，再复制整个 `storage/`、`data/`、`generated/`。私有集合还需匹配校核清单。运行中的 SQLite 主文件可能不包含 WAL 最新数据；浏览器待传草稿独立保存。

迁移电脑后恢复资料/存储，重新安装生成 `.venv/`、`node_modules/`，构建并启动。不要跨系统复制虚拟环境。保留历史会话引用的旧资源版本；项目没有远程账号能自动找回遗失本地数据。
