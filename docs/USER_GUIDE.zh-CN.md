# 使用指南

[English](USER_GUIDE.md) | 简体中文

## 启动与语言

按 [README](../README.zh-CN.md) 安装后，在项目目录运行 `npm start`，打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。保持终端运行，Control+C 停止。macOS 安装后也可双击 `scripts/start.command`。

默认界面为英文，点击顶部 **EN / 中文** 切换；浏览器用本地存储 `toefl-lab-language` 记住此站点的选择。导航、准备、反馈和帮助随语言变化。原文章、题干、姓名、选项、转写与音频保持原语言，避免翻译改变考试内容。每份文档标题下都有 English/简体中文链接。

不同浏览器档案或端口使用不同站点存储，可能恢复默认。语言切换不重启会话，也不增加作答时间。

## 第一次练习

1. 空题库首页点击 **Try the demo / 体验演示题**，安装四屏原创读写示例，无音频、不限时；也可运行 `npm run demo`。
2. 选择演示或已导入套题。R/L/W/S 直达单科，整套入口使用该档案可用范围。
3. 选择可用模式和路线并开始。每份资料只开放内容支持的模式。
4. 通过题面作答，准备好后点 Next；后台保存接受的答案。
5. 完成或结束练习进入复盘，核对答案、阅读可用解析，以后可从历史打开。

加入自己的题目或媒体，请进入 **Help & setup / 使用与导入指南** 并看[资源导入](IMPORTING.zh-CN.md)。公开代码不包含原私有 18 套题库；自定义包是不限时辅助练习，即使包含四科也不是完整官方模考。

## 选择模式

| 模式/路线 | 适用场景 | 行为 |
| --- | --- | --- |
| 辅助练习 | 学习和回看 | 在支持范围内暂停、重听、复盘 |
| 严格计时 | 符合条件的校核套题 | 服务器截止时间、导航限制、原音一次、无暂停/即时答案 |
| 原套固定路线 | 保留来源编排 | 不补造缺题、不拼接无关材料 |
| 模拟自适应 | 首模块及上下分支完整、可核验的档案 | 按首模块原始正确率分流，默认 70% 走 upper，不是 ETS 专有算法 |
| 不限时补充练习 | 自定义包与 Essentials | 不套用 iBT 单题时限，支持的播放/录音由用户操作 |

开始前阅读简短准备信息，详细来源告警和校验在答题区外。严格入口不可用通常是资料/媒体未核验、来源冲突或补充格式，不是付费门槛。

## 各题型如何作答

| 题型 | 操作 |
| --- | --- |
| Complete the Words | 行内只输入缺失字母；给定字母保留。空宽/字母标记说明需输入数量，Tab 切换输入。 |
| 阅读选择 | 阅读左侧材料，选择选项；较长材料使用内部滚动。 |
| 听力 | 先播放原音；短答选项可能显示但灰色禁用，启用后作答；严格听力不能回退。 |
| Build a Sentence | 点击、键盘或支持的拖放把词块放入空槽。固定词和标点保留，重复词仍是不同词块。 |
| Email | 读左侧情境与要求，在右侧原 To/Subject 下写作。 |
| Academic Discussion | 读教授及两位学生观点，再在编辑器贡献观点；原资料有头像时显示来源头像。 |
| Listen and Repeat | 听一遍，在录音窗口复述；严格练习按规则自动录停。 |
| Interview | 听原提问，在录音窗口作答，不新增新版考试没有的准备时间。 |

字数统计辅助写作；讨论建议 100 词等要求不是阻止提交的软件门槛。严格写作关闭拼写辅助和外部粘贴，内部 Cut/Paste/Undo/Redo 根据状态可用。

## 时间与导航

来源流程为 Reading → Listening → Writing → Speaking，说明、播放、作答、录音分开。资料包含 Begin 阶段时，点击它才启动对应任务/模块时钟。官方整科约计时间不作为四个可自由分配的大倒计时。

阅读和组句可在允许的模块/任务内返回与检查，提交模块不可重开。听力只向前；空答手动 Next 提示不阻止服务器超时。邮件/讨论各自计时；Time Remaining 确认仍倒数，Back 回同一编辑器，Continue 离题。v5 到时保留已接受答卷为只读，点 Continue 继续；旧会话保留冻结规则。

截止时间由服务器决定，刷新、后台或重启客户端不重置。计时作答时等待保存确认后前进；截止后到达的请求可能被拒绝。[官方规则](OFFICIAL_RULES.zh-CN.md)区分已核实值与本地默认，包括尚未核实官方初始值的组句六分钟。

## 音频、麦克风与恢复

使用当前 Chrome 或 Edge，按需戴耳机，完成准备页音量/麦克风检查。需要口语时给本地地址麦克风权限，选正确输入，录一小段并确认回放能听清。其他站点授权不等于这里已授权。

录音分段上传至本地服务。出现待上传提示时保持页面和服务可用，让重试完成；不要清除站点数据。中断后可建立新 take 并保留旧 take；缺片段或结束标记时，即使部分能播也仍不完整。

严格模式恢复会记录中断，仍可继续支持的练习，但该次不会被当成连续无中断表现。普通本地网页不能提供正式考场锁机/监考。设备和网络症状见[故障排查](TROUBLESHOOTING.zh-CN.md)。

## 复盘、分数与错题

历史可查看已接受答案、来源解析、作文、录音回放/下载。来源没有解析时，明确标为本地辅助的功能可对照字母/词块或定位已导入原文，不调用 AI，也不凭空编语义解释。

客观题只对可靠键核分，未解决冲突排除分母。作文/口语保存后按量表 0–5 自评；未评不是 0。软件不把正确率/自评换成 ETS 官方 1–6 或 120 分。

新完成会话冻结客观成绩，后续升级不静默改旧分。旧记录无快照时标明重新计算。迟到录音及后来自评作为独立补充。

错题集汇总已结束、实际作答且可核分的客观错误。可重练、在后续答对后标掌握，或打开最后错误；过去错误仍保留。来源/答案键变化时历史继续存在，直接重练可能需要恢复匹配资源。

## 备份、迁移与升级

没有账号和云同步，应一起保留：

- `storage/`：SQLite、原录音、回放缓存。
- `data/` 与 `generated/`：来源、复制的资源包/版本、规范化题目及注册表。
- 原私有导入还需要匹配的 `scripts/verified_*.json`。

等待待上传录音完成，停止服务后复制完整目录。不要只复制运行中的 `practice.sqlite3` 而遗漏 WAL。浏览器中待上传内容不包含在文件夹备份中。JSON 会话导出含答案和录音引用，音频需另下载或备份录音目录。

升级前备份，依赖变化时重新安装，运行 `npm run build` 并重启 `npm start`。已有会话冻结原来源和规则；资源包替换后新建练习使用新版。保留历史会话时不要删除其引用的旧资源版本。
