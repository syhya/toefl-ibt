## 已确认并复验关闭的问题

| 级别 | 修复前问题 | 隔离复现 | 修复后结果 |
| --- | --- | --- | --- |
| P1 | 历史记录形成答案试探接口 | 严格会话保持 active，另开同题单题 practice，分别提交 B/A 并结束；`GET /api/sessions` 返回 `correct: 0/1, total: 1`，即使 feedback 为403，仍能试出答案 | 严格会话期间隐藏其他考试分数，并禁止其他练习开始或继续 |
| P2 | 新建或预先打开的练习可绕过音频单次播放 | 严格会话 active 时，另一个 timed practice 的普通 `sessions/.../assets/...` URL 仍200返回原音频 | 其他会话的题面、推进事件和普通媒体入口统一被锁定 |
| P1 | 必要学术文章图片被过滤 | 原段落图 `role=passage` 是部分学生／教师阅读题唯一的文章；活动响应和资源授权仅允许 stem，因此文章消失 | 阅读题同时允许已登记的 passage 角色，题面输出和资产授权保持一致 |

上述 passage 图片修复发生在全结构化迁移之前。当前活动题面使用结构化文字和必要视觉，禁止旧整题图；历史修复不表示应重新开放这些旧截图。

第一项属于直接的答案旁路：单题正确数已经足以泄漏答案，不需要返回逐题 answer 字段。只限制 review/feedback 或只禁止新建练习都不够，还必须覆盖预先创建的练习和历史分数。

## 其余检查结果

- 严格会话活动时，`/api/validation`、`/api/questions` 和原资料 `/api/library/...` 均403。此次审查时 validation 已有全局锁，没有发现其返回原键的当前漏洞。
- 跨会话 review、export、review-assets 和录音回放受全局严格会话门禁保护。
- `/generated/audit.json`、`/generated/question-bank.json`、`/generated/exams/...`、直接 `/materials/...` 和 `/storage/...` 不作为公共文件入口提供。
- `/api/catalog`、`/api/exams/...`、`/api/rules` 保留元信息访问；隔离夹具中的答案、解析、听力原文标记没有进入这些响应。
- 活动答题响应使用字段白名单；`answer`、参考键、校核依据、完整原文及解析通过结束后的复盘接口提供。资料核验警告在活动题面中被泛化。
- 题目资源仍按当前题和播放阶段授权，而不是仅凭知道资产编号就可读取。
