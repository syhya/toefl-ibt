## 自动检查覆盖

标准命令：

```sh
.venv/bin/python -m unittest discover -s tests/data -v
```

1. 目录只含约定的 18 套来源档案；题目 ID 唯一，不含 E2E、synthetic 或 placeholder 档案。
2. 393 个有效原文件逐一检查路径、字节数与实际 SHA-256，并要求非隐藏磁盘文件集合与目录完全一致；56 份 PDF 重新读取页数。
3. 每个题目均关联真实原题 PDF、合法页码与实际印刷题号。原文未印题号的 92 个屏幕有明确说明，不把应用编号伪称为印刷编号。
4. 小题数、屏幕数、可交互数、可核分分母与模块预期值一致；Essentials 交互数与排除项合计等于原题数。
5. 题面、正文音频、说明和提示音路径存在；音频源文件、声明的 SHA、区间、WAV 可解码性与导出时长一致。直接使用原文件的资产经原文件 SHA 检查覆盖。
6. 章节、模块和参考资料的嵌套资源链接存在，题目资产中不允许 `_analysis` 私有转写缓存或测试夹具路径。
7. 161 个复制屏幕的 canonical 指针可解析；各版本 `editionSource` 的 PDF、页码、SHA 和 URL 一致。
8. 缺字模板对每个空恰使用一个占位符，原给字母、缺失字母、后缀与完整词结构一致。
9. 选择题原答案必须属于原选项 ID；组句仅验证已给答案能使用已有词块与固定位置拼出，不推断唯一答案。
10. Essentials 必须保持 `supplemental: true`、`strictEligible: false`、`timingPolicy: untimed`；缺提示题不可计入可交互或自动评分数量。
11. 全部1,518个结构屏幕与私有校核记录逐项比对来源身份、展示字段、原裁图和必要视觉摘要；`source-verified` 不是仅检查一个标签。
12. 教师90道听说题的活动块只允许原操作指示或原问题；转写只能复盘。向内存副本加回原文时门禁拒绝，移除音频时相应严格范围关闭。
13. 纯色 PDF 临时测试覆盖原PDF变化后的页面重渲染、相同来源缓存复用、无来源的旧缓存拒绝，以及 Pack 分栏缓存随真实页面图变化失效；不包含新编考试题。
14. Pack/Paid的33个听说模块说明与清单一致，原说明接入可以重复执行；缺少说明清单时关闭受影响的听说严格范围，Pack 1首题的原说明与刺激播放结束后才开始回答倒计时。

没有私有 `data` 和生成目录的公开检出会跳过这组真实资料测试，不会向主题库注入测试题。导入中读取到变化快照时需等导入完成后重跑。

## 结论范围

本验收确认来源可追踪、题数与数据结构一致、资产可访问、已知缺项不会被伪装成原题，并检查了上述重点图像和音频内容。音频核验包含本地 ASR、声学边界和源文对齐，不代表逐秒人工听校；`humanReviewed` 与自动 `verified` 分开记录。自动化检查不能证明所有 OCR 字形均无误，原图及审计来源仍是复核依据。

ETS 专有选题模型、标定参数、等值与官方分数不属于数据验收能够证明的范围。公开规则与本地计时假设详见 `OFFICIAL_RULES.md`，媒体方法与限制详见 `MEDIA_SEGMENTS.md`。原资料、派生题库和私有校对 JSON 保持本地使用，不随公开源代码分发。
