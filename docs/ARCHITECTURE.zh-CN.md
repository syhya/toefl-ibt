# 架构与开发说明

[English](ARCHITECTURE.md) | 简体中文

TOEFL Local Lab 是单用户本地网页应用。React 呈现练习界面，FastAPI 管理会话状态并只返回当前阶段允许显示的内容，SQLite 与本地媒体目录保存用户作答。安装依赖或获取资料需要网络，安装后的日常练习不需要。

## 目录职责

| 路径 | 职责 |
| --- | --- |
| `src/App.tsx`、`src/pages.tsx`、`src/components.tsx` | 导航、题库、准备、历史与共享控件 |
| `src/Exam.tsx`、`src/Questions.tsx` | 考试阶段与按来源排版的题型交互 |
| `src/types.ts` | 前端题目、会话、答案与复盘合同 |
| `public/styles.css`、`public/fonts/` | 本地样式和附许可证的字体 |
| `backend/app.py` | HTTP 路由、请求验证、活动/复盘字段投影、资产授权 |
| `backend/engine.py` | 版本化考试状态机、截止时间、导航与评分 |
| `backend/storage.py` | SQLite 持久化与录音元数据 |
| `backend/catalog.py`、`backend/integrity.py` | 题库能力与源文件/派生资产校验 |
| `backend/presentation.py` | 结构化题面校验及白名单 |
| `backend/media.py` | 录音容器与回放准备 |

| `backend/practice_groups.py` | 原模块 / 类别题组、成员版本指纹和整组进度 |

| `tests/`、`backend/tests/` | 界面、API、安全、导入与真实资料检查 |

## 请求与状态流转

1. 前端读取题库元信息与所选套题的可用能力。
2. 新会话冻结路线、源题和规则版本；更新后已有会话不会静默改用新时限。
3. 引擎确定当前说明、媒体、作答、录音、超时确认或结束阶段。
4. API 按明确白名单返回当前题面。参考答案、解析、转写与原题证据只用于复盘。
5. 作答/事件请求携带会话与题目身份；服务器先检查阶段和截止时间。迟到答卷不会变成下一题的回答。
6. 完成时一次性冻结客观分数，后续自评与录音状态不重写原客观快照。

前端计时器只显示服务器截止时间。刷新、切换后台或重启客户端不会产生新截止时间；推进测试时钟的功能仅存在于隔离 QA 工具中。

## 结构化题面

题目使用 `presentationSchema: structured-v1`、`structuredContentStatus` 和有类型的 `stemBlocks`。材料包含段落、说明、标题、消息、对话、列表、表格、高亮句、表单位置图和必要视觉；输入使用明确的 `choices`、`passageTemplate`/`blanks`、`tokens`/`slots`。

填词占位符只替代缺失字母，原给前后缀留在文章里。组句槽保留固定文字、标点、重复词和干扰词；不能用答案反推新的题干。

活动 `assets` 仅保存作答必要的原照片、头像、场景或地图，需要具体语义替代文字、`role: essentialVisual` 与高清来源证据。整题裁图仅放入复盘用的 `sourceEvidenceAssets`。`source.page` 是从 1 开始的物理 PDF 页码，`source.originalNumber` 是印刷题号，可能与应用位置不同。

私有资料导入中，仅有 `source-verified` 标签不够；校核文件绑定源文件、页码、内容身份、视觉范围和派生文件摘要。可移植自定义资源是独立的创作流程，其校验不证明 ETS 来源。见[资源导入](IMPORTING.zh-CN.md)。

## 评分与历史

可靠客观答案参与正确数/分母统计，未解决冲突排除出分母。作文和口语保存原回答并提供量表自评，不自动换成 ETS 官方分数。

`scoreSnapshot` 在完成或主动结束时冻结所选题的客观结果、分母、引擎版本与时间。旧记录没有快照时标为 `legacy-recomputed`，不会补写成当时已冻结的历史分数。迟到的有效录音及后续自评不改变该快照。

错题集只汇总已结束、实际作答且可客观核分的题。再次答对后保留过去错误。题目版本改变不会静默替换历史答案；来源失效时可能关闭直接重练，但仍保留复盘。

## 录音与存储

MediaRecorder 生成带索引的分段，服务器不使用不同内容覆盖已有分段。每次录音还保存最终分段数和结束原因；缺少结束标记或片段时，即使能播放部分音频也仍算不完整。

中断后的录音建立新 take 并保留旧 take。浏览器 IndexedDB 暂存待上传片段，服务短暂中断后可以重试。支持的录音完整后，项目内 FFmpeg 通过流复制重建可拖动回放的容器，不重新编码或改变原分段。

| 位置 | 内容 |
| --- | --- |
| `storage/practice.sqlite3` | 会话、答卷、截止时间、事件、成绩和录音元数据 |
| `storage/practice.sqlite3-wal`、`storage/practice.sqlite3-shm` | 运行时可能存在的 SQLite 附属文件 |
| `storage/segments/` | 原录音分段 |
| `storage/playback/` | 可重建的回放缓存 |
| 浏览器 IndexedDB | 待上传片段，不包含在仅文件系统备份中 |

备份应先停服务再复制整个 `storage/`，或正确使用 SQLite 在线备份；只复制运行中的主数据库可能遗漏 WAL 更新。

## 本地安全边界

服务监听 `127.0.0.1`，没有多用户鉴权或监考模型。活动严格会话会阻止其他练习、历史成绩试探、复盘、原资料及其他会话媒体形成绕过。资产根据当前题目及阶段授权，不以“知道编号”作为权限。

这些限制保护应用内部流程。有本机访问权的人仍可打开自己的 PDF 或读取本地文件，项目不是操作系统锁机客户端。改变网络监听或添加远程访问前阅读 [SECURITY.md](../SECURITY.zh-CN.md)。

## 扩展项目

添加题型时同步修改类型、结构校验、活动字段投影、渲染器、导入器与有意义的行为测试；含答案字段不能进入活动响应。时间修改应保留证据、更新规则版本并验证旧会话兼容。注释解释不明显的约束与设计原因，特别是阶段转换、来源摘要和截止时间，避免只复述代码。

界面翻译与原考试内容分开；语言切换不能改变答案、题目身份、录音或截止时间。导入改动应在安装前完成候选验证并保留用户记录。见[贡献指南](../CONTRIBUTING.zh-CN.md)和[测试说明](TESTING.zh-CN.md)。
