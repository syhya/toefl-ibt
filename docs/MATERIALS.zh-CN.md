# 本地资料与导入校验

[English](MATERIALS.md) | 简体中文

本页描述原私有集合及其专用导入器，数量仅对应有日期的个人资料快照。公开检出和新内容请从[可移植资源导入](IMPORTING.zh-CN.md)开始。


`data/` 中的原文件保持不变。生成的题库、OCR、裁图、音频片段和来源校核文件仅留在本机，不应随公开源码发布。

2026-09-05 当前清点范围是 396 个文件：393 个有效资料文件，以及 3 个 `.DS_Store` 系统元数据文件。有效资料包括 56 份 PDF（1582 页，其中 1348 页为扫描/不可直接提取文字页面）、319 个音频文件和 18 个视频文件。系统文件单列在 `catalog.excludedSystemFiles`，不作为题目。2026-09-02 原始快照中的 321 个有效文件均保留原字节；新增的 72 个 MP3 来自 ETS 当前公开提供、与两套教师 PDF 配对的官方音频压缩包。

## 可重复导入

首次安装导入依赖后，在项目根目录运行：

```sh
.venv/bin/python scripts/import_materials.py --ocr-all --jobs 6
```

依赖见项目 `requirements-import.txt`，另需 Tesseract English 语言包。已有 `generated/` 时启动软件不需要重新 OCR，也不上传任何题库或录音。

两套教师版的官方音频已安装至原教师资料目录下的 `official-audio/`。`.venv/bin/python scripts/attach_teacher_audio.py` 可离线核对 72 个原音文件，`--install` 仅在文件缺失且本地官方压缩包摘要匹配时补装，不覆盖不同内容。私有 `scripts/verified_teacher_audio.json` 记录 ETS 来源链接、压缩包和逐文件摘要、原 PDF 页码及原转写摘要。导入器在原题结构校核后关联音频，再检查活动题面是否已经移除听说原文，最后计算严格资格。

PDF 内容变化或旧缓存没有原文件摘要时，页面图必须重新从当前 PDF 渲染，不能把旧图的 OCR 结果标记为新来源。Pack 分栏 OCR 缓存另外绑定实际页面图 SHA；无摘要的旧缓存只会重新提取。启动软件不触发这些重新提取步骤。

Pack/Paid的听说说明由 `scripts/attach_pack_directions.py` 在结构校核后恢复，私有 `verified_pack_directions.json` 逐模块保存原PDF通则与情境、来源页及明确的原音片段。33个模块保留原说明，44段已核对原音用于22个模块与13个题组；题组标题只在组首播放，说明声音不消耗回答倒计时。没有核对通过的说明音轨保留原文字，不补造或合成声音。

必须一起备份：

- `data/`：用户原资料。
- `generated/`：完整题库、源页、裁图、音频片段和校验结果。
- `scripts/verified_*.json`：对照原题、答案表与音频进行的 10 份本地来源校核；这些文件被 Git 忽略。音频的自动比对与 `humanReviewed` 单独记录，不把自动核验宣称为逐秒人工听校。

缺失所需来源校核文件，或原文件 SHA-256 与校核时不同，导入器关闭相应严格资格，并报告需要重新核对。不会仅凭套数、题号或 OCR 猜测补造题目。

## 题库输出

| 文件 | 用途 |
| --- | --- |
| `generated/catalog.json` | 完整资料清单、套题目录、补充资料目录、能力与限制 |
| `generated/exams/*.json` | 原套题编排；保留每道题的原文件、页码、原题号、模块与审核状态 |
| `generated/question-bank.json` | 按内容去重后的题库，保留各套题的引用实例 |
| `generated/deduplication.json` | 重复题引用、答案冲突、修正状态与依据 |
| `generated/audit.json` | 文件覆盖、题量、答案、资产路径、音频关联与严格资格检查 |
| `generated/extracted/*.json` | 原生提取或本地 OCR，包含源页坐标，不用作考试时的答案接口 |
| `generated/media-segments.json` | 原声片段的来源、起止时间、置信度、等待时段与版本差异 |

可移植包另外使用 `generated/pack-catalogs/` 注册表，其自编内容校验与此私有校核流程分开。

完整题库 JSON 包含复盘答案、原文和解析，**不得直接发送给正在考试的前端**。应用服务必须通过白名单生成当前可见题面，结束后才提供答案、解析和原文。

## 数据约定

- `source.page` 是 PDF 的物理页码，起始为 1；`source.originalNumber` 保留印刷题号。资料印错或漏印题号时，只对已有原题建立本地顺序号，并记录差异。
- `type` 指交互控件，例如 `choice`、`cloze`、`build_sentence`、`email`、`academic_discussion`、`listen_repeat` 和 `interview`。`taskType` 区分阅读日常材料/学术文章，以及听力对答/会话/通知/学术讲座，共覆盖新版十二种任务。
- 填词保存 `prefix`、可选 `suffix`、`missingLetters`、`fullWord`、`length` 与 `acceptedAnswers`。`passageTemplate` 中每个 `{{blankId}}` **仅替代缺失字母**，已给字母留在模板原文里。每个空出现一次。
- 无唯一可靠答案的空，`answer`、`missingLetters`、`fullWord` 为 `null`，并标注冲突。此空不计入自动判分分母。
- 组句保留原有词块顺序、重复词块、多余词块和固定文字。`slots` 中 `{id: ...}` 是一个可填词块位置，`{fixed: ...}` 是原题已经印出的文字；`expectedTokenOrder` 仅用于交卷后核验，不能出现在活动考试响应中。
- 组句通过“原有词块 + 原有固定文字能够组成参考句”的校验。终句标点及大小写差异不应导致误判。原参考键与原题结构矛盾时，保留 `sourceReferenceAnswer`、`answerConflict` 和 `resolutionEvidence`，并明确标为本地题面校核结果。
- 阅读涉及段落关系时保留段落间距。原页裁图保留为来源证据；结构尚未可靠恢复的题不能只凭文字截图宣称活动题面已经通过结构化校核。当前1,518个题目屏幕均已结构化，不把多个段落混成一个。
- `audio` 只关联对应原声音频或已核验的原声片段。原段落共用 `groupId`，不能在组内每题重播。提示音使用 `cueAudio`，作答等待不包含在刺激片段内。

## 结构化题面与来源图

活动题面使用 `presentationSchema: structured-v1`、`structuredContentStatus` 和 `stemBlocks`。段落、消息、对话、列表、表格、突出句、表单位置图和问题分别保存为有类型的块；原有 `choices`、`passageTemplate`、`tokens` 与 `slots` 继续负责交互。只有逐页核对且状态为 `source-verified` 的结构题才能进入练习，不能用一次 OCR 的结果自动取得该状态。

原整题裁图移入 `sourceEvidenceAssets` 并强制 `reviewOnly: true`，仅在练习结束后的来源核对中开放。活动 `assets` 只允许从原 PDF 高分辨率重裁的必要照片、人物、场景或地图，并要求 `role: essentialVisual`、`highResolution: true`、具体语义 `alt`，以及对应的 `essential_visual` 块或 `dialogue.turns[].avatarAssetIndex` 引用。可用 HTML 表达的文字、表格、高亮句和表单位置不保留为活动截图。

18道学术讨论写作题的结构对话均按原顺序保存教授和两位学生三轮发言，并通过 `[0, 1, 2]` 三个头像索引绑定原页人物。54个题次引用复用48个唯一裁图；两个 Paid 版本复用对应 Pack 原页素材。头像从16个唯一原 PDF 页面按校核范围以4倍重建，不使用整题裁图、生成头像或外部人物素材。

6套Pack的60道组句题另保留原题上下两人的头像，20道Paid同题引用复用其对应原图；共160个头像引用、120个来源明确的4倍裁图。`assets[0]` 对应原对话提问者，`assets[1]` 对应原组句作答者，结构顺序为首头像、原对话文本、次头像。纸版原页未印头像的题不添加人物。全部60个原页的句末标点另经目视核对：缺失标点以最后一个固定 `slot` 恢复，不新增空槽、词块或参考答案。

Pack 4的社交帖子Q11–12保留原框内上方的彩色环状人物图标，两题共用物理第4页的184×184原PDF裁图；第5页的同材料引用另记录 `stimulusSource`。原邮件边框、滚动条和手机轮廓由界面表达，不把材料中的整段文字变成截图。

每条结构校核记录绑定原资料 SHA、物理页、导入前内容身份和旧裁图 SHA；跨页材料另存 `stimulusSource`。每个必要视觉还绑定归一化裁切范围、渲染倍率、输出 SHA 和尺寸。`scripts/extract_structured_visuals.py` 从原 PDF 重建视觉，不放大旧 JPEG；缺少裁切规格、记录级哈希或内容身份不匹配时，导入失败而不是沿用旧结构。

界面字体与题目来源分别核对。现行ETS公共客户端所引用CSS已经确认默认控件使用Open Sans，本地字体文件与许可证随界面资源保存；这不能推定每个嵌入式邮件、图文材料都使用相同字体，也不改变题库原文字。静态规则和实际界面对照范围见 [EXAM_UI_REFERENCE.md](EXAM_UI_REFERENCE.zh-CN.md)。

## 作答快照、客观评分与错题集

每次练习保存所选路径的原题、参考答案、作答和来源摘要。新记录在完成或主动结束时一次性保存 `scoreSnapshot`，包含该次原始客观评分、可核分分母、计分引擎版本与计算时间。后续修改题库答案或升级判分代码不会静默重算已经冻结的客观成绩；读取历史和复盘也不会改写该快照。旧记录若原来没有评分快照，明确标为 `legacy-recomputed`，使用旧题目与作答按当前判分代码计算，不补写成当时已经冻结的结果。

迟到的有效录音片段和量表自评仍可更新复盘。它们可以补充录音完整性及界面中的已作答数量，但不会改动已冻结的客观正确数或分母。这里的来源快照、客观评分快照和录音完整性是不同状态，均不代表ETS官方成绩。

错题集从已结束练习的实际作答汇总，只收录有可靠客观评分且曾答错的题。整题未作答、仅填写无可靠答案的缺字空，以及作文或口语自评都不会被伪判为客观错题。再次答对后标为已掌握，仍保留过去的错误次数与最后一次错误复盘；再次答错可重新进入待复习。题目版本区分题文、媒体和参考键等变化，旧错题不会因同一个 `contentId` 被悄悄换成新答案或新版本。来源缺失、改变或未通过校验时保留历史记录，并关闭不再匹配的直接复练入口。

## 资料分类与限制

资料目录中有 15 套 iBT 相关编排，包含彼此重复的版本与真实的高低分支；不是 15 套互不重复的独立题目。“补充套题 1/2”的原文件夹名称仍保持用户提供的名称，软件没有购买、会员或解锁机制。

另有 3 套 TOEFL Essentials 补充练习。它们与 2026 iBT 分开，不套用 iBT 正式流程或评分，也不能进入 iBT 严格模考或自适应分流。

当前 14 套 iBT 编排可严格计时，包括补齐官方原声后的两套教师样题；Student 1 仍因采访第 1 题纸音版本冲突而关闭完整严格模考。教师版的 90 道既有听说题只在活动题面显示原纸印出的操作指示、问题及选项，完整原文保留至复盘；没有新增题目。3 个教师音轨的结尾等待静音以来源区间明确的 WAV 片段排除，完整原 MP3 仍留档。音频缺失或来源发生变化会使相应范围不可严格计时，不合成或改写“官方”题目补齐。

阅读和听力正确数、正确率仅反映本地题目核对；造句按题面校核，作文与口语按资料量表自评。软件不生成未经校准的 ETS 1–6 分或 120 分成绩。

最终可交互题数、独立内容数、各分支题量、待核项目与严格资格以本次导入生成的 `audit.json` 为准；不以“题库已收录”代替题面、答案和媒体均已通过校验。
