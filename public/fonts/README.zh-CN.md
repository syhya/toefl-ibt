# Open Sans

[English](README.md) | 简体中文

这些未修改的 WOFF2 文件是 normal 样式的 Latin/Latin-ext 可变字体，来自公开 ETS TOEFL 客户端工具栏样式明确引用的 Google Fonts CSS，核对日期为 2026-09-05。

- `open-sans-latin-wght-normal.woff2`：Latin，字重 300–800。
- `open-sans-latin-ext-wght-normal.woff2`：Latin-ext，字重 300–800。
- `OFL-OpenSans.txt`：原版权声明与 SIL Open Font License 1.1。

[公开客户端入口](https://ibt2-toefl-pt.ets.org/ibt2tcweb/themes/toeflCompat/index.html)直接引用 `styles/toolbarToefl.css`，该样式导入[对应 Google Fonts CSS](https://fonts.googleapis.com/css2?family=Open+Sans:ital,wght@0,300..800;1,300..800&display=swap)。

[字体项目与许可证](https://github.com/googlefonts/opensans)。精确字体 URL、SHA-256、CSS 字符范围保存在本地 `tmp/qa/ets-client-static/local-woff2-fonts.json`。字体自托管以便离线使用；获取时没有使用注册编号、账户 Cookie 或题目内容。这不证明完整考试会话最终 CSS 级联，也不覆盖各原始材料自身的字体选择。
