# Open Sans

These unmodified WOFF2 files are the normal-style Latin and Latin-ext variable
fonts explicitly referenced by the Google Fonts stylesheet imported by the
public ETS TOEFL client toolbar stylesheet, checked on 2026-09-05.

- `open-sans-latin-wght-normal.woff2`: Latin, weights 300-800.
- `open-sans-latin-ext-wght-normal.woff2`: Latin-ext, weights 300-800.
- `OFL-OpenSans.txt`: original Open Sans copyright notice and SIL Open Font License 1.1.

[Public client entry](https://ibt2-toefl-pt.ets.org/ibt2tcweb/themes/toeflCompat/index.html)

The entry directly references `styles/toolbarToefl.css`, which imports:

[Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Open+Sans:ital,wght@0,300..800;1,300..800&display=swap)

[Font project and license](https://github.com/googlefonts/opensans)

Exact font URLs, SHA-256 digests and CSS unicode ranges are preserved in
`tmp/qa/ets-client-static/local-woff2-fonts.json`. The fonts are self-hosted for
offline use. No registration identifier, account cookie or test content was used
to retrieve them. This does not establish the final CSS cascade of a live exam
session or override font choices embedded in individual original materials.
